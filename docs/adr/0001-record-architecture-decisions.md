# 1. Record architecture decisions

Date: 2026-08-01

## Status
Accepted

## Context
This project will make a series of decisions (language, solver,
UI framework, deployment shape) that are expensive to reverse and
easy to forget the reasoning behind. Following the same convention
used in glasshouse.

## Decision
Use Architecture Decision Records, one per significant decision,
numbered sequentially, following Michael Nygard's format. Record them
here in docs/adr/.

## Consequences
Anyone (including future us) can see why a decision was made, not
just what was decided.
